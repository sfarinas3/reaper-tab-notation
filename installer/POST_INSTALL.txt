Installation complete. ReaImGui and ReaPack (REAPER's own extensions this
script needs) were installed automatically.

On the next page, a checked checkbox offers to "Finish setup
automatically" - leave it checked and click Finish. This opens REAPER
(or hands off to it if it's already running) and registers everything:
the viewer becomes a REAPER action, and a one-click button is added to
the Main toolbar. If REAPER was already open, close and reopen it
afterward so the toolbar button appears (REAPER only reads its toolbar
layout at startup); if REAPER just opened fresh because of this step,
you're already set.

===============================================================
If that checkbox didn't appear, or setup didn't seem to work
===============================================================
This happens if REAPER's install location couldn't be found automatically
(e.g. a non-standard install). Do these two steps by hand instead - both
use REAPER's "Load ReaScript" feature:

STEP 1: Load main.lua
1. In REAPER's main menu bar, click Actions > Show action list...
2. In the Action List window that opens, click the "New action..."
   button (bottom-left), then choose "Load ReaScript...".
3. A file browser opens. Go to the folder you installed to - if you're
   not sure where that is, in REAPER click Options > Show REAPER
   resource path in explorer/finder, then open the Scripts folder, then
   reaper-tab-notation.
4. Select main.lua and click Open.
5. main.lua now appears in the Action List, already selected/
   highlighted. Click "Run" (or just double-click it) to open the
   viewer - it docks like any other REAPER window.

STEP 2: Add the toolbar button
1. Actions > Show action list... (same window as Step 1).
2. "New action..." > "Load ReaScript..." again.
3. This time select install_toolbar_button.lua, from that same folder.
4. Select it in the Action List and click "Run" (or double-click it). A
   message box confirms it was added.
5. Restart REAPER - the new button then appears on the Main toolbar.

===============================================================
Using it
===============================================================
Select a MIDI item on a track and the tab/notation view will appear.

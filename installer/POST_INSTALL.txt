Installation complete. ReaImGui and ReaPack (REAPER's own extensions this
script needs) were installed automatically - if REAPER was open during
setup, restart it now so they load.

Two things left to do before the viewer shows up in REAPER. Both use the
same REAPER feature ("Load ReaScript") - full steps below.

===============================================================
STEP 1: Load main.lua (one-time)
===============================================================
1. In REAPER's main menu bar, click Actions > Show action list...
2. In the Action List window that opens, click the "New action..."
   button (bottom-left), then choose "Load ReaScript...".
3. A file browser opens. Go to the folder you installed to - if you're
   not sure where that is, in REAPER click Options > Show REAPER
   resource path in explorer/finder, then open the Scripts folder, then
   reaper-tab-notation.
4. Select main.lua and click Open.
5. main.lua now appears in the Action List, already selected/
   highlighted. Click "Run" (or just double-click it) to open the
   viewer - it docks like any other REAPER window.
6. To find it again later without redoing these steps: open the Action
   List, type "tab" or "notation" in the filter box at the top, and
   double-click main.lua in the results. (Step 2 below sets up a
   one-click toolbar button instead, so you won't need to do this.)

===============================================================
STEP 2: Add a one-click toolbar button (one-time, optional but
recommended)
===============================================================
1. In REAPER: Actions > Show action list... (same window as Step 1).
2. "New action..." > "Load ReaScript..." again.
3. This time select install_toolbar_button.lua, from that same folder.
4. Select it in the Action List and click "Run" (or double-click it).
   A message box confirms it was added.
5. Restart REAPER - reaper-menu.ini (REAPER's toolbar layout file) is
   only read at startup. After restarting, a new button appears on the
   Main toolbar that opens the viewer directly - no more Action List.

===============================================================
Using it
===============================================================
Select a MIDI item on a track and the tab/notation view will appear.
